**`unsat` is a proof.** Every asserted constraint is satisfied by every
real configuration (validated exactly: see README §6.2), so an `unsat`
rules out all general-position realisations -- indeed all generalised
(pseudo-)configurations, which is stronger than a straight-line result.
In particular `generic / both-hooking` and `generic / both-hooked` are
`unsat`, which is exactly **Lemma 7 / A7-EXT**.

**`sat` is not a claim of realisability.** A satisfiable oriented matroid
need not be realisable by points. The `sat` rows only show the `unsat`
rows are not vacuous.

## 5. Bottom line

* **Lemma 7 / A7-EXT is verified** by the oriented-matroid unsatisfiability
